# Public Authority Data Request Log

This log records all requests received from public authorities (government agencies, law enforcement, regulators) for users' personal data or personal information, per the [Public Authority Data Request Policy](./public-authority-data-request-policy.md).

Note: This does not include requests related to search warrants or court orders associated with criminal investigations — track those separately per standard legal process if applicable.

## How to use this log

Add one entry per request received. If no requests have been received, leave the table with the header row only — that itself is a record that none have occurred as of the last review date.
